Workload: (regex, text, replacer, limit) cases. S holds every case of tests/replace.rs plus edge cases (empty text,
no match -> borrowed result, empty-match regexes `""`, `^`, `x*`, `\b`, lone trailing `$`, missing groups,
closures with limits); M/L hold 2-6 KB / 20-60 KB texts generated by `driver.rs` (splitmix64) from words, digits and whitespace plus non-ASCII and invalid UTF-8 bytes.
Replacers: plain literal, `$`-template, NoExpand, counting closure; limits 0 (all), 1, 2, 7, 50. Regexes are compiled before timing.
Invocation: `driver.rs` is appended to `src/re_bytes.rs` of a container-local copy (`/tmp/w`, `/w` untouched) and run with `cargo test --release`;
`check` hashes Borrowed/Owned, closure call count and the output bytes (FNV-1a 64).
