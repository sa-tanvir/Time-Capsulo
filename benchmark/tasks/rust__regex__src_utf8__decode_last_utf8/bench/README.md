Workload: byte buffers. S holds the literal sequences of the utf8.rs unit tests plus edge cases (empty, ASCII, every
sequence length, boundary code points, overlong forms, surrogates, > U+10FFFF, truncated sequences, stray and excess
continuation bytes), each decoded once as a whole, plus short generated buffers; M/L hold 2-6 KB / 30-90 KB buffers
generated by `driver.rs` (splitmix64) mixing 1-4 byte characters with 0-100% invalid material, walked backwards by
repeatedly calling `decode_last_utf8(&buf[..i])` (step back by n on success, 1 on failure).
Invocation: `driver.rs` is appended to `src/utf8.rs` of a container-local copy (`/tmp/w`, `/w` untouched); `cargo test --release`; `check` hashes every result (FNV-1a 64).
