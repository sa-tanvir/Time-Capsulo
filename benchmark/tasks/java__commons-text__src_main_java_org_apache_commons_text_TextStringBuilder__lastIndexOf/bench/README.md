First line: a haystack over the alphabet a-d (60, 6 000 or 400 000 chars). Each following line is 'startIndex<TAB>needle': needles taken from the haystack, random absent ones, empty ones, ones containing characters that only occur in stale buffer space past the logical size, a null needle (token <null>), with start indices inside, beyond and below the valid range. The driver builds a TextStringBuilder whose buffer has spare capacity filled with stale characters beyond size and calls lastIndexOf(String,int) for every query (check mode also queries an empty builder). TCBench.java is in package org.apache.commons.text, compiled against target/classes and commons-lang3 into /tmp/tcb.
