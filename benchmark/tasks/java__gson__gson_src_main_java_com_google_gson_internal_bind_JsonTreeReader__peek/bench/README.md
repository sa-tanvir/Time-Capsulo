Each workload line is a JSON document tree to read through JsonTreeReader: X = explicit JSON text (parsed with JsonParser), G = generated (seed, node budget, max depth, max fan-out; random objects/arrays/strings/numbers/booleans/nulls under a top-level array). The second field selects the read script: F full walk, P walk that also calls peek() twice and hasNext() at some tokens, S walk that skips values/names with skipValue() at some tokens, M walk that provokes IllegalStateException by wrong next*() calls at some tokens, D walk that peeks twice after END_DOCUMENT, C reader closed before peek().
The driver (package com.google.gson.internal.bind, compiled against gson/target/classes into /tmp/tcb; /w is never modified) walks each tree: peek() is public, so it is called directly; in check mode every peeked token, the path every 8th token and every exception message are digested. Trees are built outside the timed region; time mode times the full walks (peek dominates together with the next*/begin*/end* calls that consume tokens).
Sizes (documents x nodes per document, max depth): S 120 x ~30 (depth 3), M 200 x ~500 (depth 8), L 60 x ~20,000 (depth 40).
