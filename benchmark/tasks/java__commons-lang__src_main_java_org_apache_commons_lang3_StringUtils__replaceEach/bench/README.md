Cases of (text, search array, replacement array, repeat flag, timeToLive). The text is a random sequence of short words over a-h (repeated 1/4/160 times for S/M/L, so the text grows from about 60 to 160 000 characters); the search strings are words that occur in it, the replacements come from a disjoint alphabet (plain, repeated and chained variants, null entries, empty strings), plus edge cases (null/empty text and arrays, mismatched lengths, negative timeToLive) in S. The driver calls the private static `StringUtils.replaceEach(String, String[], String[], boolean, int)` via reflection (looked up once, outside the timed region) and hashes the result or the exception class and message. TCBench.java is in the same package as the target.
