Cases of (string, separatorChars, max, preserveAllTokens). The string is built from random lowercase words, some empty, glued by one to three separator characters (single-char separators, multi-char sets, null = whitespace), with optional leading/trailing separators, and repeated 1/3/220 times for S/M/L (so a case grows from about 60 to about 3 million characters). max is 0, negative, small or large. S also has edge cases (null/empty input, empty separator string). The driver calls the private static `StringUtils.splitWorker(String, String, int, boolean)` via reflection (looked up once, outside the timed region) and hashes the length-prefixed result array. TCBench.java is in the same package as the target.
