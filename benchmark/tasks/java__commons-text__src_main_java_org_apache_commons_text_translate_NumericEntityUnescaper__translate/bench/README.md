Strings built from random tokens (plain letters, well-formed and malformed numeric entities, hex and decimal, supplementary code points, overflowing and out-of-range values, bare '&#'). For each of four option configurations (default, semiColonOptional, errorIfNoSemiColon, semiColonRequired+errorIfNoSemiColon) the driver calls translate(input, index, writer) at every index of every string and hashes return values, written chars and exception classes. TCBench.java is in the same package as the target, compiled against target/classes and commons-lang3 into /tmp/tcb.
