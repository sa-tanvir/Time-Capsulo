Each workload line is one map scenario: either E (explicit op list) or G (generated: ops count, seed, put%, remove%, key pattern R=random, A=ascending, D=descending, Z=zigzag). Keys are Key(name, hash) objects (names k0000000.., hash = (index % hashmod) * 40503; hashmod controls how many keys share a hash), comparator natural (N) or reversed (R). Operations: put, remove, get, find(key,false), find(key,true), containsKey and (explicit cases) find on a non-Comparable object.
The driver (package com.google.gson.internal, compiled against gson/target/classes into /tmp/tcb; /w is never modified) runs the ops on a fresh map per scenario and in check mode digests every result plus the final size, iteration order and tree shape (keys, heights, parent links, table size and threshold). In time mode only the ops are timed; the maps are created outside the timed region. LinkedHashTreeMap.rebalance is exercised through put/remove/get (private; called by put (insert) and remove (delete), shape verified through the tree dump).
Sizes (scenarios x ops x key space): S 60x20x30, M 100x300x200, L 150x6000x3000.
