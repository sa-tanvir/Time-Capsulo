The driver bundles `/w/src/moment.js` with rollup (the target is the exported `configFromStringAndFormat` of `src/lib/create/from-string-and-format.js`), builds a fresh creation config per call (`_i`, `_f`, `_strict`, `_useUTC`/`_isUTC`, `_locale`, as `createLocalOrUTC` does) and digests every property of the config afterwards (sorted keys; Dates as time values).
Locales: 'en' and a driver-defined French-like 'tc-fr' (exact month/weekday parsing, own long-date formats and meridiem). `moment.now` is pinned to 2019-01-21T12:00:00Z so defaulted date parts are reproducible.
Workload: inputs rendered from random dates with the same format (names, ordinals, meridiem, offsets, ISO week/ordinal dates, L/LL/LLL/LLLL macros), ~35% corrupted; strict 40%, UTC 30%. S also has test-suite cases (ISO_8601/RFC_2822 constants, bigHour, 24:00, overflow, unix timestamps).
S/M/L grow the per-call input: formats with ~1 / ~10 / ~100 time groups (input ~25 / ~150 / ~1,500 characters; 2,000 / 300 / 40 calls).
