`baseClone` is internal; the driver calls the public `_.clone`, `_.cloneDeep`, `_.cloneWith` and `_.cloneDeepWith` (customizer replacing Dates and some instances) from `require('/w/lodash.js')`, which call it directly.
Workload (built before timing from a seed): object graphs of ~n nodes shaped as a 6-ary tree, a single wide object, a 300-level nested chain (further nodes attached at random), or a tree with extra shared and circular references to near-root nodes; containers are plain objects (some with enumerable and non-enumerable symbol keys), arrays (some with expandos), Maps, Sets and class instances; leaves are primitives, Dates, RegExps with lastIndex, boxed primitives with expandos, typed arrays, symbol objects, plus uncloneable functions and errors.
Nodes per case 500-1,000 / 5,000-10,000 / 50,000-100,000 (S/M/L), 16 cases each; S adds 1-20 node cases for every method and shape.
The digest covers a canonical walk of every clone (types, prototypes, keys, values, symbol keys, shared/circular identities, and which objects are original references).
