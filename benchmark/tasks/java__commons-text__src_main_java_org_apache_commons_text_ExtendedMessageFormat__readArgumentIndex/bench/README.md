Pattern strings with a start position: well-formed argument indices followed by ',' or '}', with leading or interior whitespace, non-digit characters, missing terminators, overflowing numbers and non-zero start offsets. The driver calls the private readArgumentIndex via reflection on an ExtendedMessageFormat instance with a fresh ParsePosition per case (created outside the timed region) and hashes the returned index or exception class and message plus the final ParsePosition index. TCBench.java is in package org.apache.commons.text, compiled against target/classes and commons-lang3 into /tmp/tcb.
