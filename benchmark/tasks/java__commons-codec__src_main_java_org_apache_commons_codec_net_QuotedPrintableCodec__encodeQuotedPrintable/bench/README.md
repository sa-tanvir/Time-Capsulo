Calls QuotedPrintableCodec.encodeQuotedPrintable(BitSet, byte[], strict) on generated bytes mixing letters, blanks, tabs, CR/LF, '=' and arbitrary high bytes. Lines: strict printableKind length seed (kind 0 = null BitSet, 1 = alphanumerics, 2 = visible ASCII except '='). Strict inputs have length >= 3 except a few S cases that exercise the failure path.
The driver is TCBench.java in the same package as the target; it compiles against target/classes (build output goes to /tmp/tcb). It reads /task/bench/workload_<size>.txt produced by gen_workload.py.
