Pairs of 32-bit ints: all combinations of special values (0, +-1, powers of two, Integer.MIN_VALUE/MAX_VALUE) in S, plus random pairs (unrelated operands, operands sharing a common factor, operands with many factors of two); operand magnitude grows from 12 to 22 to 31 bits and the case count from 150 to 20 000 to 300 000 for S/M/L. The driver calls the private static `Fraction.greatestCommonDivisor(int, int)` through a MethodHandle obtained by reflection (outside the timed region) and hashes each result or exception class and message. TCBench.java is in the same package as the target.
