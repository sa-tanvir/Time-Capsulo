Workload: one App per line (DontCollapseArgsInUsage on/off) with a list of positionals, each optionally Required,
Hidden, Last, Multiple, with value names, or a member of a required / optional ArgGroup. S holds hand-written edge cases
(no positionals, one optional, several optional, required-group members, hidden/last, value-name forms); M/L hold
50-500 and 500-5000 positionals generated by the driver (xorshift) at 0-30% flag densities.
Invocation: `driver.rs` is appended to `src/app/usage.rs` of a container-local copy (`/tmp/w`, `/w` never modified) as
`mod tc_bench`; apps are built before timing; each app is evaluated with `get_args_tag(&app.p, true)` and
`get_args_tag(&app.p, false)`. `check` hashes the rendered `Option<String>` results (FNV-1a 64).
