Workload: (app, template) pairs over three apps (all meta set / bare / bin_name with a space). S holds the template
tests' templates plus every tag and malformed-brace edge case (empty, `{}`, unclosed `{`, tags of 14/15+ bytes,
`{?}`, unknown tags) for each app; M/L hold 300-3000 and 3000-30000-piece templates generated by the driver (xorshift)
from a weighted mix of plain text, cheap tags, malformed braces and rare section tags (`{flags}`, `{usage}`, ...).
Invocation: `driver.rs` is appended to `src/app/help.rs` of a container-local copy (`/tmp/w`, `/w` never modified) as
`mod tc_bench`; one `Help` writer (colour off, width 120) over an in-memory sink is reused and
`help.write_templated_help(&app.p, template)` is called. `check` hashes written bytes + Ok/Err per case (FNV-1a 64).
