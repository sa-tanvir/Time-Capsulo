Workload: (Unicode class, query characters) cases. S holds hand-written classes (single range, \w-like ASCII and Latin-1
sets, full range, everything-but-one, U+2028-2029, astral planes) with boundary queries and absent characters, plus
small generated classes; M/L hold classes of 60-200 / 1500-4000 sorted, non-overlapping ranges generated by `driver.rs`
(splitmix64) over the BMP or all scalar values, each with 300 queries (range bounds +/-1, random, ASCII, absent).
Invocation: `driver.rs` is appended to `src/prog.rs` of a container-local copy (`/tmp/w`, `/w` untouched); `InstRanges`
values are built before timing and `matches(Char)` is called for every query; `check` hashes all booleans (FNV-1a 64).
