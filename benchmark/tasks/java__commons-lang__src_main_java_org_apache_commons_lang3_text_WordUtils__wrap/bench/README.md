Cases of (text, repetition, wrapLength, newline string, wrapLongWords, wrapOn regex). Texts are random lowercase words (1 to 10 characters, longer in some S cases) joined by separators that fit the regex (space, hyphen, comma, `[ ,;]+`, `[-/]`, null/empty/blank = default), repeated 1/2/120 times for S/M/L (from about 60 characters to about half a million), with wrap lengths 1-30/15-90/15-100 and several newline strings (including null = platform line separator, which is `\n` in the container). S also has edge cases (null, empty, wrapLength <= 0, Integer.MAX_VALUE, invalid regex). The driver calls the public static `WordUtils.wrap(String, int, String, boolean, String)` and hashes the result or the exception class and message. TCBench.java is in the same package as the target.
