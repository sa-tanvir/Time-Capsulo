Templates mix plain words and many variable syntaxes (known/unknown names, defaults, nested `${${key}}`, escapes, unclosed prefixes, other prefix/suffix styles) and are repeated 1/4/400 times for S/M/L (a case grows from about 50 to 20 000+ characters with up to thousands of variables); a few cases contain cyclic references (IllegalStateException). The driver builds 7 StrSubstitutor configurations over one fixed map (default `${}`/`$`/`:-`; `<<`/`>>` with `!` escape and `|` default delimiter; substitution in variable names; preserved escapes; `%` as prefix and suffix; no default delimiter; `:=` delimiter with both options), and calls the private `substitute(StrBuilder, int, int, List)` via reflection with `priorVariables = null`. It hashes the return value and the resulting buffer text. In time mode the StrBuilder inputs are rebuilt outside the timed region before every repeat. TCBench.java is in the same package as the target.
