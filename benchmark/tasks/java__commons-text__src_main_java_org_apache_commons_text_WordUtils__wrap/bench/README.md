Each workload line is: wrapLength, newline-string id (null, LF, '<br />', CRLF), wrapLongWords flag, wrap-on regex id (null, empty, space, '/', '[ ,;]+', '-', '\s', ' +', '[,.]'), and a text of generated words (including long URLs and runs of separators). The driver calls the public static WordUtils.wrap(String,int,String,boolean,String) directly and hashes the result (or the exception class). The workload avoids regexes that match the empty string. TCBench.java is in package org.apache.commons.text, compiled against target/classes and commons-lang3 into /tmp/tcb.
