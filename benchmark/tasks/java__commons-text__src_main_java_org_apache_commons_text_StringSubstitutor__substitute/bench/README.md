Templates of random text mixed with variable references: plain, undefined, with default values (including nested defaults), escaped ($${..}), nested in the name (${v${n0}}), unterminated or empty, and two cyclic variables. The driver defines a fixed map of about 40 variables (some whose values reference other variables) and four StringSubstitutor configurations (default; substitution in variable names + preserve escapes; no substitution in values; undefined-variable exception + substitution in names). It calls the private substitute(TextStringBuilder,int,int,List) via reflection on a freshly built TextStringBuilder (rebuilt outside the timed region, since the call mutates it) and hashes the return value, the buffer contents or the exception. Check mode also runs a sub-range (offset 3). TCBench.java is in package org.apache.commons.text, compiled against target/classes and commons-lang3 into /tmp/tcb.
