Cases of (format string, repetition). Formats are random sequences of pattern-letter runs (y M d H m s S), unquoted punctuation and letters that are not pattern letters, and quoted literals (including empty ones and quote characters), with balanced quotes, repeated 1/3/80 times for S/M/L (up to about 150 000 characters per format); S also has hand-written edge cases and a few unterminated quotes (IllegalArgumentException). The driver calls the package-private static `DurationFormatUtils.lexx(String)` and hashes the tokens (kind, text or letter, count) or the exception class and message. TCBench.java is in the same package as the target.
