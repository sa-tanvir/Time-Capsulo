The driver bundles `/w/src/moment.js` with rollup (the target is the exported `configFromISO` of `src/lib/create/from-string.js`), builds a fresh creation config per call (`_i` = string, no format, `_strict`, `_useUTC`/`_isUTC`, 'en' locale) and digests every property of the config afterwards (sorted keys; Dates as time values). `moment.now` is pinned to 2019-01-21T12:00:00Z.
Workload: extended/basic calendar dates, signed 6-digit years, week dates, ordinal dates, year-month, with 'T'/space times (hh, hh:mm, hh:mm:ss, '.'/',' fractions, basic forms), zones (Z, +hh, +hh:mm, +hhmm), leading whitespace, plus near-misses (time after week-only/year-month dates, bad time forms, out-of-range parts, junk); S also has the ISO test-suite strings.
Each input has bounded length, so S/M/L scale the call count: 2,000 / 20,000 / 200,000 (L = 40,000 distinct cases used 5 times).
