Encodes pseudo-random byte arrays (generated in the driver from a seed) through Base32.encode with a fresh Context per case: fed in chunks of the given size, then end-of-input is signalled. Workload lines: lineLength useHex sepKind chunk length seed. Output digest covers the produced bytes and the Context counters. Scales with input length (S ~tens of bytes, M ~thousands, L ~hundreds of thousands).
The driver is TCBench.java in the same package as the target; it compiles against target/classes (build output goes to /tmp/tcb). It reads /task/bench/workload_<size>.txt produced by gen_workload.py.
