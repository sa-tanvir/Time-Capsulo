Workload: varint byte buffers. S holds single encodings (the unit-test round-trip shapes: 1-5 byte values up to u32::MAX,
redundant 0x80 padding, empty input, unterminated inputs, trailing bytes after the varint), each decoded with one call,
plus short generated streams; M/L hold streams of 500-3000 / 20000-60000 varints generated by `driver.rs` (splitmix64),
optionally ending in an unterminated tail, decoded front to back by advancing by the returned length until it is 0.
Invocation: `driver.rs` is appended to `src/dfa.rs` of a container-local copy (`/tmp/w`, `/w` untouched); `cargo test --release`; `check` hashes every (value, length) pair (FNV-1a 64).
