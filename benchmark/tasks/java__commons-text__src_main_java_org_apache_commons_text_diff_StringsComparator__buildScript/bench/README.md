Pairs of strings over a 10-letter alphabet (mutated copies and unrelated strings). The driver builds a fresh StringsComparator and EditScript per case outside the timed region and calls the private buildScript over the full ranges via reflection, then hashes the rendered edit script (keep/insert/delete commands, LCS length, modification count). TCBench.java is in the same package as the target and is compiled against target/classes and commons-lang3 into /tmp/tcb.
