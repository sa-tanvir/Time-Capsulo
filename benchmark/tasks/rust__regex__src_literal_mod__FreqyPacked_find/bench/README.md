Workload: (needle, haystack) pairs. S holds the needles/haystacks of the unit and regression tests in src/literal/mod.rs
plus edge cases (haystack shorter than / equal to the needle, occurrence at the very start or end, overlapping
self-similar needles, empty needle); M/L hold 4-12 KB / 40-120 KB haystacks generated by `driver.rs` (splitmix64)
over English-like text, DNA, binary, uniform-byte and mostly-zero alphabets, with 1-64 byte needles, 0-300 near-miss copies and an optional planted match.
Invocation: `driver.rs` is appended to `src/literal/mod.rs` of a container-local copy (`/tmp/w`, `/w` untouched); searchers are built with
`FreqyPacked::new` before timing and `find(&[u8])` is called; `check` hashes every result (FNV-1a 64). Run with `cargo test --release`.
