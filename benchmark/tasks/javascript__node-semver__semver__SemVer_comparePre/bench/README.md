Calls `a.comparePre(b)` on SemVer objects built outside the timed region; their `prerelease` arrays are replaced by generated lists.
Per-case prerelease length: 0-6 / 30-90 / 300-900 identifiers (S/M/L), half numbers half tags; pairs share a long common prefix (equal, prefix, extension, or a late difference).
S adds the test-suite pairs, each also with `other` passed as a string. Digest: the -1/0/1 results.
