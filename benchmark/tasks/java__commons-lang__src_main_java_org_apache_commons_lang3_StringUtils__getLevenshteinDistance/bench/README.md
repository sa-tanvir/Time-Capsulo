Triples (s, t, threshold) of strings over a small alphabet: mutated copies and unrelated strings, thresholds from 0 up to far above the real distance (also Integer.MAX_VALUE), plus edge cases (empty strings, null, negative threshold). The driver calls the public static `StringUtils.getLevenshteinDistance(CharSequence, CharSequence, int)` and hashes the result (or exception class and message). S/M/L use string lengths of about 12/150/2500 characters. TCBench.java is in the same package as the target and is compiled against target/classes into /tmp/tcb.
