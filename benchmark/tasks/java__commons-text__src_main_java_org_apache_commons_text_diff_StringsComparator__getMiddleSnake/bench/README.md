Pairs of strings over a 10-letter alphabet (mutated copies and unrelated strings) with an index range (start1,end1,start2,end2): the full range plus random sub-ranges. The driver builds a fresh StringsComparator per case outside the timed region and calls the private getMiddleSnake via reflection (method lookup outside the timed region), hashing the snake's start, end and diag (or null). TCBench.java is in the same package as the target and is compiled against target/classes and commons-lang3 into /tmp/tcb.
