Strings given as prefix + middle*repeat + suffix: integers, octal-looking numbers, hex with various prefixes, L-suffixed longs, decimals with exponents and type suffixes, and malformed strings (a stray character inserted), plus about 150 hand-written edge cases (many from the unit tests) and a null in S. Digit runs grow up to 30/3000/1 500 000 characters for S/M/L (valid and invalid at the very end). The driver calls the public static `NumberUtils.isCreatable(String)` and hashes the boolean results. TCBench.java is in the same package as the target.
