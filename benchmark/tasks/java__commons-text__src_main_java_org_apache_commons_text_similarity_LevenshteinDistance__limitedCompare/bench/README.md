Triples (left, right, threshold) of strings over a small alphabet: mutated copies and unrelated strings, thresholds from 0 up to far above the real distance, plus edge cases (empty strings, null, negative threshold). The driver calls the private static limitedCompare via reflection (looked up once, outside the timed region) and hashes the result (or exception class and message). TCBench.java is in the same package as the target and is compiled against target/classes and commons-lang3 into /tmp/tcb.
