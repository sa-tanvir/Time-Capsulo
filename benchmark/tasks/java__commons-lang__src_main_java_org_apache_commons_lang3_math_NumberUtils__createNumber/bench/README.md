Strings given as prefix + middle*repeat + suffix: plain and huge integers, octal-looking numbers, hex with 0x/0X/#/sign prefixes of 1 to 33 digits (around the int/long/BigInteger boundaries), L-suffixed longs, decimals with exponents and f/F/d/D suffixes (around the Float/Double/BigDecimal boundaries), and malformed strings, plus about 150 hand-written edge cases (many taken from the unit tests) and a null in S. Mantissas grow up to 30/80/3500 digits for S/M/L; strings never contain both 'e' and 'E' except in S edge cases. The driver calls the public static `NumberUtils.createNumber(String)` and hashes the result class and value (or just `NumberFormatException`). TCBench.java is in the same package as the target.
