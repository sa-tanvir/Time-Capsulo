Each workload line: reader chunk size (max chars per Reader.read; 0 = unlimited), S/L (strict/lenient), number of calls, prefix, unit, repeat count, suffix; the input text is prefix + unit*count + suffix (ASCII-escaped). Texts are numeric literals (integers, fractions, exponents, long-range and overflow values, malformed numbers, terminators).
The driver (package com.google.gson.stream, compiled against gson/target/classes into /tmp/tcb; /w is never modified) creates a JsonReader over the text, primes its buffer with the private fillBuffer(1) via reflection, calls the private method peekNumber via reflection, and records the result, any exception (class and message) and the consumed character offset. In time mode readers are built outside the timed region in batches of 200.
Sizes: S: ~100 fixed edge cases x2 + random numbers up to 12 digits; M: ~120 digits; L: up to ~1000 digits (a few around the 1024-char buffer limit).
