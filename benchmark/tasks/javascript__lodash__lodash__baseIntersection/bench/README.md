`baseIntersection` is internal; the driver calls the public `_.intersection(...arrays)`, `_.intersectionBy(...arrays, iteratee)` and `_.intersectionWith(...arrays, comparator)` from `require('/w/lodash.js')`, which delegate straight to it.
Workload: 2-4 arrays per case generated before timing from a seeded LCG over a shared key domain: integers with -0/+0 and NaN, strings, shared objects (fresh copies in the other arrays for the iteratee mode), mixed primitives with symbols, floats; other arrays are as long as the first, half of it, 150 or 30 elements; iteratees are a floor key function or `'id'`, comparators `_.eq` or id-equality (40x shorter arrays in that pairwise mode).
First-array length 500-1,000 / 5,000-10,000 / 50,000-100,000 (S/M/L), 40 cases each; S adds tiny/empty arrays.
The digest covers each result element (sign of zero, NaN, symbols, object ids and reference identity).
