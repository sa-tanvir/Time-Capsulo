Cases of (array length or -1 for null, startIndexInclusive, endIndexExclusive, offset, seed). Arrays are filled by a seeded generator in the driver; ranges cover the whole array, large sub-ranges, out-of-range indices and offsets from small to +-Integer.MAX_VALUE. Array length is about 12/3000/6 000 000 for S/M/L. The driver calls the public static `ArrayUtils.shift(byte[], int, int, int)`; arrays are rebuilt outside the timed region before every repeat, and the digest covers the array after the call. TCBench.java is in the same package as the target.
